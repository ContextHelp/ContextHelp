# Web Docs (context.help)

This folder defines the public website for **context.help**.

Scope:

- Positioning and messaging (what we say)
- Target audience (who we speak to)
- Design system (how it looks)
- Web stack (how it is built)

Non-goals:

- Product documentation (see `docs/`)
- Implementation of the cloud service or node runtime

## Files

- `docs/web/messaging.md` - Core messaging, copy blocks, CTAs
- `docs/web/target-audience.md` - Personas, pains, jobs-to-be-done
- `docs/web/design-system.md` - Visual direction for the marketing site
- `docs/web/stack.md` - Tech stack and deployment assumptions

## Inputs

Messaging should reflect the project's core principles (sovereign, federated,
polyglot, verifiable) while also explaining the optional **context.help cloud**
offering.
