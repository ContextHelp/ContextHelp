# Web Design System (context.help)

This is a lightweight design direction for the public marketing site.

## Brand direction

Keywords:

- precise
- editorial
- technical but welcoming
- trust-forward

Avoid:

- generic SaaS gradients
- "AI magic" vibes
- purple-on-white default aesthetics

## Typography

Recommended pairing:

- Headings: "Fraunces" (variable serif)
- Body: "IBM Plex Sans" or "Inter" fallback

Rules:

- Headlines are short and declarative
- Use tight line length on long-form pages (60-75 chars)

## Color

Base:

- Ink: #111111
- Paper: #FBFAF7
- Accent: #0F766E (teal)
- Accent 2: #B45309 (amber)

Use accent sparingly for links, tags, and highlights.

## Layout

- Hero: editorial headline + short subhead + 2 CTAs + 3-5 proof bullets
- Mid-page: publisher story + buyer story
- Bottom: marketplace + trust + OSS boundary

## Components

- Registry card (title, category, what’s inside, pricing hint)
- Proof strip ("thin sync", "JIT pull", "receipts")
- Callout blocks for OSS vs cloud separation
- Code-like snippets for protocol/receipts (small, not intimidating)

## Motion

- One entrance animation per section (fade + slight rise)
- Optional stagger for cards
