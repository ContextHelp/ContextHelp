# Marketplace

The marketplace is the distribution and monetization layer for:

- paid registries (curated context feeds)
- paid extensions (plugins, pipelines, templates)

## Core objects

- Publisher
- Listing
- Subscription plan
- Trial
- Credit meter (optional)

## Security and trust

- Signed publisher identities (optional)
- Receipts for JIT pulls and exports
- Abuse controls (revocation, rate limits, anomaly detection)

See `docs/policy/receipts-and-traceability.md`.
