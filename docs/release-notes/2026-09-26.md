## Changes by bucket

### `none` changes (no operator impact at the data layer)

#### Browser capture

- **`ctxt capture tabs`** sends the tabs open in one Chromium-family browser profile (Chrome, Brave, Edge, Arc, Chromium, Vivaldi). Reads the profile's session file; no extension needed. `--dry-run` lists every tab with its allow/deny reason.
- **`ctxt capture history`** sends browsing history. No time flag: incremental from a saved position (first run looks back `capture.history.initial_lookback`, default `24h`). `--since` alone captures from that time and advances the position. `--until` / `--range` backfill without touching it. `--reset-position` clears one profile's position.
- **`ctxt capture browsers`** lists installed browsers and profiles and shows what auto-selection would pick.
- **`ctxt capture schedule install|uninstall|list`** manages macOS LaunchAgents that run the two capture commands on a timer, pinned to one browser profile.
- `--browser` is optional everywhere: flag → `capture.browser` → the only browser with that profile name → OS default browser.
- `capture.url_filter` deny rules add up across every config layer (user file, project file, `-c` files and values); no layer can remove one.

#### Config

- Config loading never writes files. The v0→v1 migration and its write-back into the highest-precedence file are removed, along with the `version` key.
