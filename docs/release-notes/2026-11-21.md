## Changes by bucket

### `reingest_selective` changes

- **What changed** — the `html_cleaner` step. It parses HTML instead of stripping tags with regular expressions. Page chrome is dropped: `head`, `script`, `style`, `noscript`, `template`, `nav`, `iframe`, `svg`, form controls (`input`, `select`, `textarea`, `button`, `option`), elements with `hidden` or `aria-hidden="true"`, page-level `header`, `footer` and `aside` (those inside an `article`, `main` or `section` stay), and elements with the landmark roles `banner`, `navigation`, `contentinfo`, `complementary`. Text comes from `<main>` (or `role="main"`), else the outermost `<article>` elements, else the body. If that leaves nothing, the step retries keeping everything except `head`, `script`, `style`, `template` and `noscript`. Page chrome is removed by structure only: a cookie notice in the body outside every landmark stays. The page title moves from the body text to the `title` metadata key. Documents nested more than 512 elements deep use a simpler text pass (no `<main>` or `<article>` preference, no roles).
- **Pipelines affected** — `url.generic`, `url.repo`, `url.github.issue`, `url.github.pr`, `url.github.release`, `url.github.profile`, `url.github.starred`.
- **Stored pages** — unchanged by this release. The fetched HTML is not kept, so the new cleaner cannot run on pages already stored. They are refreshed by the daemon in a later release; no command is needed now.
- **Recapture** — the stored content hash describes the text the old cleaner produced. Capturing an already-stored URL again creates a second object instead of reinforcing the first, until the refresh lands.
