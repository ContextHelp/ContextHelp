# Feature Set (`ctxt` Only)

## Universal Capture Layer (Every Interface)
First-class capture from CLI, TUI, REPL, browser extension, web UI, and mobile
share sheet with offline-first behavior, instant “inbox dump” mode, and zero
required classification at capture time.

## Multimodal Ingestion Recipes (Powered by dPKMS Pipelines)
Opinionated, configurable enrichment recipes for text, URL, image, audio, video,
documents, code snippets, and chat transcripts — using dPKMS pipeline runtime and
job execution under the hood.

## Progressive Enrichment (Raw → Refined)
Capture first, structure later. Raw inputs become progressively enriched over time
into structured knowledge objects with summaries, sections, tags, mentions, tasks,
decisions, and composition-ready outputs.

## Focus Profiles (Role / Project Lenses)
Profile-driven scoping and ranking reshapes retrieval, surfacing, pipeline
selection, and composition defaults for modes like Founder, Engineer, Research,
Family, or “Project X”.

## Just-In-Time Surfacing (Contextual Memory)
Proactively resurfaces the right knowledge at the right moment based on active
projects, recent work, time windows, people, and profile context — without noise.

## Search That Forgives You
Fast discovery designed for uncertainty: fuzzy search, semantic search, filters,
entity-aware lookup, and graph-informed exploration through a single command flow.

## Composition Engine (From Nodes to Shipments)
One-command generation of briefs, plans, checklists, meeting packets, drafts,
messages, and publish-ready artifacts assembled from atomic nodes and graph context.

## Action Layer (Decisions, Tasks, Follow-Ups)
Extract and manage next steps, decisions, follow-ups, and commitments, with
lightweight workflows that convert knowledge into momentum.

## Safe Agent Execution (Propose → Dry Run → Apply)
Agent behaviors run with explicit scopes, previewable changes, reversible actions,
and audit-friendly outputs — avoiding silent automation and unintended writes.

## Personal Relevance Model (Learned Ranking)
Learns what “useful” means through implicit feedback (opens, reuse, exports,
ignores) and adapts ranking, surfacing, and defaults over time.

## Controlled Sharing Workflows (Trust-Aware)
User-driven publishing, subscription management, collaboration flows, and boundary
controls that integrate with dPKMS permissions without exposing data by default.

## Multi-Language Composition (Polyglot Outputs)
Language-aware enrichment and generation that supports mixed Arabic/English/French
inputs, profile-specific language preferences, and multilingual writing styles.

## Plugin-Driven UX Extensions
Extensible commands, templates, profiles, surfacing rules, and composition modes
built on top of the dPKMS plugin system and capability contracts.
