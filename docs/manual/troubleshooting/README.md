# Troubleshooting

Use this section when behavior differs from expectation in ingestion, search, composition, or extensibility paths.

## Fast triage path

1. Validate runtime and config.
2. Check ingestion/job health.
3. Verify retrieval quality and latency.
4. Verify composition output and provenance.
5. Isolate extension/registry issues.

Start here: [`faq.md`](./faq.md)
